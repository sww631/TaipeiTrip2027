🟢 動線 1｜Day 1：桃園機場 → 凱達大飯店 → 東區燒肉 → 南機場夜市

時間軸：13:55 抵達桃園 → 約 15:40–16:45 抵酒店（視出關及交通）→ 17:45–19:15 燒肉擔當 → 20:00–21:15 南機場夜市。

交通診斷：酒店至東區需預留約 35–50 分鐘，17:45 訂位要以實際入住時間為前提；若航班或出關延誤，先聯絡餐廳。燒肉後再去夜市，只建議分享 1–2 款小食。

商家提醒：燒肉擔當建議預約並確認訂位；南機場夜市以飯後散步為主，個別攤位售完或休息不影響主行程。

🟢 動線 2｜Day 2：十分 → 九份點燈 → 台北西門無老鍋

時間軸：09:30–12:00 十分 → 12:30–18:15 九份 → 約 20:00 後無老鍋。17:00 前到豎崎路、阿妹茶樓附近等候，日落後欣賞紅燈籠亮起。

交通診斷：十分與九份之間轉乘較繁複，建議包車；九份 18:15 離開後回台北車程會受路況影響，無老鍋訂位宜安排 20:00 或稍後，並先確認延遲入座安排。

商家提醒：九份老街小食及茶樓可按現場人流彈性選擇，不要把每間店都當成必到；無老鍋請預約，並預留交通緩衝。大聯盟已移出 Day 2，不再與九份點燈及晚餐爭時間。

🟡 動線 3｜Day 3：中山赤峰街 → 大稻埕日落 → 寧夏夜市 → 大聯盟

時間軸：11:30–15:15 中山、赤峰街 → 16:30–17:30 大稻埕碼頭（日落約 17:19–17:22）→ 17:45–19:00 寧夏夜市 → 約 19:45–20:45 西門町大聯盟。

交通診斷：赤峰街到大稻埕建議預留交通時間；碼頭到寧夏夜市可步行；寧夏到西門町再搭車。這個順序比先去西門再折返大稻埕合理，但夜市停留要控制，避免打擊場太晚。

商家提醒：赤丸團子位於赤峰街一帶；麵線町、Zubiba、伊良可樂、灑白甜及參樓研製所宜先核實週六營業／最後點單時間。路力草莓大福可能提早售完，已取消迪化街後不再特別繞路追店。大聯盟須另行確認週六營業時間及最後入場時間，原檔的平日 22:00 時間不可直接當作週六保證。

🟡 動線 4｜Day 4：Waku + → 松菸文創 → 饒河夜市 → 彩虹橋

時間軸：12:30–14:00 Waku + → 14:00–18:00 松菸、誠品及周邊店舖 → 18:30–21:00 饒河夜市與彩虹橋。

交通診斷：松菸至饒河可步行或短程交通；彩虹橋安排在饒河夜市後段較順，記得預留往返河岸的步行時間。夜市小食建議兩人分享 5–6 款，不必硬食原清單 11 攤。

商家提醒：CREM 原資料註明只提供預訂外帶、沒有內用座位，請先確認取貨時段及是否成功預訂；三徑就荒及松菸市集需留意週日開放安排。Waku + 建議先訂位。

🟢 動線 5｜Day 5：退房寄存行李 → 小王煮瓜／龍山寺 → 取行李 → 桃園機場

時間軸：09:00–09:15 退房寄存行李 → 09:15–10:45 小王煮瓜及龍山寺 → 10:45–11:15 回酒店取行李 → 11:15–11:30 出發往機場 → 14:50 UO113 起飛。

交通診斷：不建議把一甲子、三六食粑及誠記排成多站早餐；最多額外選一間。回酒店取行李後直接出發，計程車較省搬運；機捷則須把酒店至台北車站的步行／轉乘時間計入。

商家提醒：小王煮瓜及龍山寺是主行程；週一營業與否、當日排隊及供應仍須出發前確認。航班報到／行李托運截止時間以香港快運通知為準，不要只按推算的 13:50 關櫃。

🔴 全程最重要的三個時間風險

1. Day 1：航班出關或交通延誤會壓縮 17:45 燒肉訂位緩衝，應預先確認餐廳可否延後入座。

2. Day 2：九份留到點燈後，回台北時間受塞車影響；無老鍋不宜訂得太早，建議 20:00 後。

3. Day 3：大聯盟放到週六晚間，必須確認週六營業及最後入場時間；若時間不合，優先保留大稻埕日落及寧夏夜市，打擊場改作彈性項目。
